# b5-the-adversarial-buyer
GTM Hackathon
B5
The Adversarial Buyer
Build
An agent that reads a company's site and pricing, becomes its hardest and most skeptical buyer, and tries to kill the deal. The output is a ranked list of the objections that go-to-market cannot currently survive.

Done looks like
Ranked objections, each tied to the specific line on the site that causes it.

The judge hands you
Their own pricing page.

Demo it by
Running it on a judge's company in front of the room.

Watch out
Don't ship a chat transcript. Rank by damage and quote the exact page line behind each objection.
